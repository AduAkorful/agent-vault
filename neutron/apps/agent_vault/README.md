# Agent Vault Neutron package

This directory is the sole Agent Vault implementation and packaging root.

## Components

- `backend/main.mo`: Neutron backend, approval lifecycle, real ICRC transfer and ICPSwap settlement, and durable reconciliation.
- `backend/memory/agentvault/v1.mo`: managed-memory schema and safe empty defaults.
- `backend/vault/Policy.mo`: pure transfer classification, per-token rolling spend, and policy validation.
- `backend/icrc1/`: typed ICRC-1, ICRC-2, ICPSwap factory, and pool request/response adapters.
- `src/index.tsx`: owner dashboard.
- `src/service.ts`: four-tool resident agent surface.
- `neutron.json`: method declarations, exact/method backend-call reservations, and preapproved self-calls.

## Invariants

- The vault subaccount is the custody account.
- The shared default account may be used only as an empty, exact-balance swap transit account.
- Transfers may be autonomous only within per-token fee-inclusive limits and the recipient allowlist.
- Swaps always require owner approval.
- Unknown ICPSwap pool calls are observed and unwound; they are never replayed.
- Token fees and decimals are queried, never assumed.
- Production and UI state contain no demo balances, tickets, receipts, or fallback labels.

## Commands

From the Neutron repository root:

```bash
npm --workspace neutron-agent-vault run package
npm --workspace neutron-agent-vault test
```

Frontend typecheck:

```bash
cd apps/agent_vault
../../node_modules/.bin/tsc -p tsconfig.app.json --noEmit
```

The checked-in `.neutron` archive is regenerated by the package command. Pre-release schema v1 is pinned by `neutron.lock.json`; after a live release, add a new schema version and migration instead of editing v1.
